# Keepraw-Fly v0.4.0

Stable feature release · 正式功能版本

## English

v0.4.0 gives the flight archive three dedicated views and introduces two official skins. Aviation is the default and opens on Map.

### Views and navigation

- **Log**, **Map** and **Stats** share the selected year, airport or route, airline and aircraft-type filters, and sort order. Flight Detail has its own address at `#/flight/<id>`. Reload, Back and Forward restore the addressed view and its exploration state.
- Desktop navigation and the Compact bottom tab bar provide access to all three primary views. **Add flight** stays visible in the primary views and is also available in Settings and Import.
- The header uses the same layout across views. **Share Flight Passport** is now an action in Map, and existing `#/passport` links open Map.

### Official skins

- **Aviation** is Dark-only and uses the Neon Aviation map. **Minimal** offers Light and Dark appearances and opens on Log.
- Aviation and Minimal replace the v0.3.0 visual style in the skin selector. Each skin supplies its own map theme and Flight Passport layout. Skin choices are browser preferences stored separately from the flight archive.

### Log and statistics

- Filter the more compact flight list by airline and aircraft type alongside the year, airport or route. Sort by newest, oldest, longest or shortest flight.
- Stats includes annual flight counts, distances and arrival delays, monthly flight counts, airport, airline and aircraft-type rankings, and cabin-class distribution. Records show the longest and shortest flights, longest arrival delay, and most-flown route. Ranking entries can filter the shared view.

### Aviation Flight Detail

- The Flight Detail extension compares scheduled and actual operations on one timeline when all four times are recorded for a completed, non-diverted flight.
- For flights with different known local clocks, the extension shows departure and arrival time zones together, with local midnight markers and the arrival day offset.
- When the great-circle route crosses the 180th meridian, the timeline marks the estimated International Date Line crossing based on that route.

### Import, editing and welcome

- Import has its own view with a review step for Keepraw Fly JSON, CSV, Flighty CSV and Umetrip XLS.
- The flight editor shows required fields first and groups optional fields for cancellations and diversions, ticketing and frequent-flyer details. Groups open automatically when the flight already has those details.
- The welcome page makes it easier to try the demo, start an archive, or import a file. The Keepraw Fly Great-Circle Arc brand mark appears in the header, startup screen, favicons and app icons.
- Import and recovery fixes preserve legacy ticket, baggage-carousel and frequent-flyer values during migration, retain leading zeros in XLS ticket numbers, and improve date handling, duplicate detection and airline statistics.

### Data compatibility and distribution

- Personal flight records stay in IndexedDB in the current browser profile and origin. The upgrade reads the existing archive in place using the same database and archive stores as v0.3.0.
- The app version is **0.4.0**. Full archive exports still use **`formatVersion` `0.2.0`**, and JSON import accepts both `0.1.0` and `0.2.0` archives. The production site and Docker deployment use the v0.3.0 Content Security Policy (CSP).
- The release provides static ZIP and TAR.GZ downloads and a Docker image for `linux/amd64` and `linux/arm64`, with SHA256 checksums and Sigstore provenance for the files and image. [Deployment guide](https://github.com/keepraw/Keepraw-Fly/blob/v0.4.0/docs/deployment.md)

[View architecture and skins](https://github.com/keepraw/Keepraw-Fly/blob/v0.4.0/docs/views-and-skins.md)

## 简体中文

v0.4.0 为航班档案提供三个独立视图，并引入两款官方皮肤。默认皮肤为 Aviation，首页打开地图。

### 视图与导航

- **日志、地图和统计**共享选定的年份、机场或航线、航司和机型筛选，以及排序方式。航班详情有独立地址 `#/flight/<id>`。刷新、后退和前进可恢复地址对应的视图及其浏览状态。
- 桌面导航和紧凑屏幕的底部标签栏都可切换三个主视图。**添加航班**在主视图中持续可见，也可从设置和导入页打开。
- 各视图采用统一的页眉布局。**分享飞行护照**已移至地图中，原有的 `#/passport` 链接会打开地图。

### 官方皮肤

- **Aviation** 仅提供深色外观，使用 Neon Aviation 地图。**Minimal** 提供浅色和深色外观，首页打开日志。
- Aviation 和 Minimal 取代了皮肤选择器中的 v0.3.0 视觉风格。地图主题和飞行护照版式由皮肤决定。皮肤作为浏览器偏好，与航班档案分开保存。

### 日志与统计

- 更紧凑的航班列表支持按航司、机型以及年份、机场或航线组合筛选，可按最新、最早、航程最长或最短排序。
- 统计涵盖各年的航班数、距离和到达延误，各月的航班数，机场、航司和机型排名，以及舱位分布。纪录包括最长及最短航程、最长到达延误和最常飞航线。点击排名条目可筛选共享视图。

### Aviation 航班详情

- 航班详情扩展位为已完成且未备降的航班提供时间轴。在计划起降和实际起降四个时间均有记录时，可在同一时间轴上比较。
- 两地的已知当地时间不同时，扩展同时展示出发地和到达地的当地时间，并标记当地午夜及到达日期偏移。
- 大圆航线经过 180° 经线时，时间轴会根据航线标记推算出的国际日期变更线穿越位置。

### 导入、编辑与欢迎页

- 导入成为独立流程，支持 Keepraw Fly JSON、CSV、Flighty CSV 和航旅纵横 XLS。每种格式都可先预览确认。
- 航班编辑器优先显示必填项，将取消或备降、客票和常旅客信息归入可选分组。已有对应记录时，分组会自动展开。
- 欢迎页更便于试用示例、创建档案或导入文件。页眉、启动页、网站图标和应用图标已同步 Keepraw Fly Great-Circle Arc 品牌标识。
- 导入与恢复修复保留旧档案迁移中的票号、行李转盘和常旅客信息，保留 XLS 票号的前导零，并改善日期处理、航班去重和航司统计。

### 数据兼容性与发行

- 个人航班记录仍保存在当前浏览器配置和站点来源的 IndexedDB 中。升级会使用与 v0.3.0 相同的数据库和档案存储，直接读取现有档案。
- 应用版本为 **0.4.0**。完整档案仍按 **`formatVersion` `0.2.0`** 导出，JSON 导入支持 `0.1.0` 和 `0.2.0` 档案。生产站点与 Docker 部署沿用 v0.3.0 的内容安全策略（CSP）。
- 本次提供静态 ZIP、TAR.GZ，以及支持 `linux/amd64` 和 `linux/arm64` 的 Docker 镜像。发行包包含 SHA256 校验清单，以及文件和镜像的 Sigstore 构建来源证明。[部署指南](https://github.com/keepraw/Keepraw-Fly/blob/v0.4.0/docs/deployment.zh-CN.md)
