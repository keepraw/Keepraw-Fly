# Keepraw-Fly v0.2.0 — Flight Passport Journal

Stable feature release · 正式功能版本

Maintainer / 维护者：**keepraw**

## English

Flight Passport Journal adds a locally generated, two-page souvenir passport.
This feature release includes the changes since v0.1.1 and retains the
browser-local flight archive model.

### New: Flight Passport journal

- Choose **Share Flight Passport** from Passport to generate a **1200 × 1684 PNG**
  on your device. Two equal, TD3-proportioned leaves form a vertically opened
  journal with paper texture and a sewn binding.
- The upper page shows the complete Equal Earth world map, great-circle routes
  and airport dots using bundled geometry. The lower page shows your archive's
  saved name, a stable browser-local souvenir number, first flight, record period
  and flight statistics. Cancelled flights are excluded; Passport's year, search
  and airport filters do not limit the journal's full-archive totals.
- View the finished image in place, click or press Enter/Space to enlarge, and
  save using native right-click or long-press image actions. Escape restores the
  fitted image and then closes the viewer; focus returns to the share action.
  Generation failures offer a retry.
- Two 44-character MRZ rows implement TD3 field layout and check digits. Saved
  romanized names take precedence; Han names can use automatic pinyin. The
  fictional issuer, unspecified personal fields and fixed souvenir expiry are
  specimen policy, not personal facts inferred from flights. This is a keepsake,
  **not a travel credential or certified physical OCR document**.

The final viewer replaces the early Share Studio proposals. The removed 3:4/4:3
layout selector, editor toolbar and separate share-name editor are not available.
Edit the archive name in Settings.

### Improvements and fixes

- Refined page proportions, localized headers, holder grid, multiline name
  fitting, measured text clearance and MRZ print spacing. Dedicated Latin and
  regional CJK fonts support the existing ten interface locales and selected
  distance units, with bounded loading and system fallbacks.
- Restored a complete world-map frame, including both poles, independently of
  route distribution. Dense journals draw the busiest 60 routes; statistics
  retain all non-cancelled flights. Airport dots are unlabelled, and the finished
  image does not print map-coverage captions.
- Improved Passport home globe containment and desktop density across display
  scales, plus the content-driven Flight Detail hero and Globe composition.
- Fixed production Blob-image previews under CSP. Reduced-motion palette changes
  avoid WebKit's intermediate theme colors; Globe Lab texture-failure checks wait
  for the actual failed resource before asserting fallback.
- Patched the locked Ajv transitive dependency `fast-uri` from 3.1.8 to 3.1.9
  for four newly disclosed URI parsing advisories. Full and production dependency
  audits are clean; see the [current security review](../security.md#known-dependency-advisory).

### Engineering maintenance

- Unified development and CI on Node.js 24 and migrated to Vitest 5; updated
  dependencies and SHA-pinned Actions without weakening release verification.
- Balanced all Chromium regression files across six CI shards, retained
  Firefox/WebKit compatibility journeys and production CSP/font-SRI checks, and
  pinned the matching browser runtime. Improved persistence-test timing and
  commit-identity validation for rewritten history.
- Fixed a Globe test race by waiting for the filtered camera frame before
  checking keyboard movement and exact camera preservation across themes.
- Consolidated user, deployment and developer documentation, examples and visual
  evidence. Synthetic installer fixtures now use v99.0.0 instead of the real
  v0.2.0, preserving upgrade, rollback and provenance refusal coverage.

### Data compatibility, upgrade and rollback

Application packages advance from **0.1.1 to 0.2.0**. Archive **`formatVersion`
remains `0.1.0`**. The JSON Schema, JSON backup/import contract, mapped CSV and
Flighty CSV import behavior, and IndexedDB database version are unchanged.
Existing archives need no new format migration for this release.

**Export a full Keepraw Fly JSON backup before upgrading, and back up regularly.**
Flight records still live in the current browser origin's IndexedDB. Updating
website files does not intentionally clear them. Retain the same scheme, hostname,
port and browser profile; export/import JSON when moving origins or devices.
Docker hosts website files, **not personal flight backups**. There is no account,
cloud synchronization or server restore copy.

The souvenir identity lives separately in localStorage and is **not in JSON
backups**. Intermediate journal identities migrate deterministically from the
full legacy `KRF-…` value to a nine-character display number, preserving the
original identity and nickname without overwriting Settings. Clearing storage or
moving origins can create a different number; global uniqueness is not guaranteed.
The saved PNG includes the holder name and number: inspect it before sharing.

Docker users download and verify this release's installer, then select
`--version v0.2.0 --dir /opt/keepraw-fly`. Omit address flags to retain existing
hostname and ports. Fork Pages users select v0.2.0 in the existing official-release
workflow. Static-host users deploy the verified ZIP/tar.gz over HTTPS. See the
[deployment guide](../deployment.md) for prerequisites and commands.

Historical Releases, tags and images remain unchanged. The v0.2.0 installer can
explicitly select v0.1.1 for rollback with file/image provenance verification;
v0.1.0 remains installable as the clearly identified checksum-only legacy release.
Back up data first and retain the same origin. Restore all three managed files
(`compose.yaml`, `.env`, `.keepraw-managed`) together when using deployment history.

### Distribution and known limits

Static archives and linux/amd64 + linux/arm64 Docker images reuse the **exact
successful main Push CI build**. The existing workflow requires CI, tag and
workflow source commits to match; it generates SHA256SUMS, provenance and separate
Sigstore-backed file/image attestations. The Owner-only publisher verifies them
and anonymous image access before publishing as **keepraw**. The installer
requires GitHub CLI **2.102.0 or newer**; missing or invalid proofs stop installation.
Mocked tests do not replace real signature verification.

- Offline startup is not guaranteed. CJK passport fonts can request version-pinned,
  SRI-checked stylesheets from jsDelivr; failed requests use system fonts whose
  glyphs can differ across devices. This does not upload flight records.
- Missing distances/times can make statistics incomplete; the image does not
  print completeness warnings. Dense maps omit less frequent routes, and routes
  without usable coordinates cannot be drawn.
- Empty or unsupported names can leave the MRZ name field unpersonalized.
  Automatic pinyin is not verified passport spelling; set a romanized name in
  Settings where needed. Native image saving depends on the browser.
- Browser eviction or clearing site data can remove the only copy of records.
  Persistent-storage permission does not replace a downloaded JSON backup.

## 简体中文

Flight Passport Journal 带来在本机生成的双页旅行纪念护照。这是自 v0.1.1 以来的
正式功能升级，继续保持浏览器本地航班档案设计。

### 新增：Flight Passport 旅行纪念护照

- 在 Passport 选择 **分享飞行护照**，在当前设备生成 **1200 × 1684 PNG**。
  两个等大的 TD3 比例页面纵向展开，保留纸张纹理和缝线装订效果。
- 上页使用内置几何展示完整 Equal Earth 世界地图、大圆航线和机场点；下页展示档案
  姓名、浏览器本地纪念编号、首次飞行、记录区间和统计。取消的航班不计入；Passport
  的年份、搜索和机场筛选不会限制护照的全档案统计。
- 原位查看成品图片，点击或按 Enter/空格放大，通过浏览器原生右键或长按保存。
  Escape 先恢复整图，再关闭查看器，焦点返回分享入口。生成失败可以重试。
- 两行各 44 字符的 MRZ 实现 TD3 字段布局和校验位。优先使用已保存的罗马字姓名，
  汉字姓名可自动转为拼音。虚构签发方、未指定个人字段和固定纪念到期日属于示例策略，
  不从航班推断个人事实。它是纪念图片，**不是真实旅行证件，也未通过实体 OCR 认证**。

最终查看器替换了早期 Share Studio 方案，不提供已删除的 3:4/4:3 比例选择、编辑
工具栏或独立分享姓名编辑器；姓名在设置中修改。

### 改进与修复

- 优化页面比例、本地化页眉、持有人网格、多行姓名适配、实测文字留白和 MRZ 排版。
  专用拉丁字体和地区化 CJK 字体支持现有十种界面语言及所选距离单位；加载有时间
  上限，并提供系统字体降级。
- 恢复包含南北两极的完整世界地图，不随航线分布裁切。密集地图绘制最繁忙的 60 条
  航线，统计仍包含全部未取消航班。机场点不带标签，成品不打印地图覆盖率说明。
- 优化 Passport 首页地球的宽度约束、不同显示缩放下的桌面密度，以及按内容适配的
  航班详情 Hero 和 Globe 地图构图。
- 修复生产 CSP 下的 Blob 图片预览；减少动态效果时避免 WebKit 显示主题过渡色；
  Globe Lab 在实际贴图请求失败后再检查降级状态。
- 将 Ajv 间接依赖 `fast-uri` 从 3.1.8 补丁升级到 3.1.9，修复四条新披露的 URI
  解析告警；完整和生产依赖审计均无已知漏洞，见[当前安全审查](../security.md#known-dependency-advisory)。

### 工程维护

- 开发和 CI 统一到 Node.js 24，迁移至 Vitest 5，更新依赖和完整 SHA 固定的 Actions，
  保留既有发行安全校验。
- 将完整 Chromium 回归文件均衡分配到六个 CI 分片，保留 Firefox/WebKit 兼容测试和
  生产 CSP/字体 SRI 测试，固定匹配的浏览器环境。改进持久化测试时序和重写历史时的
  提交身份校验。
- 修正 Globe 测试的相机帧时序：先等待筛选后的画面，再检查方向键移动及主题切换时
  相机位置精确保持不变。
- 整理用户、部署和开发者文档、示例及视觉证据。安装器模拟版本改为 v99.0.0，避免与
  真实 v0.2.0 混淆；升级、回滚和来源证明拒绝场景的覆盖保持不变。

### 数据兼容性、升级与回滚

应用 package 版本从 **0.1.1 升至 0.2.0**，归档 **`formatVersion` 保持 `0.1.0`**。
JSON Schema、JSON 备份/导入契约、映射 CSV 与 Flighty CSV 导入行为、IndexedDB 数据库
版本均未改变，本次升级无需新的档案格式迁移。

**升级前导出完整 Keepraw Fly JSON，并定期备份。** 航班记录仍保存在当前浏览器来源
地址的 IndexedDB 中，更新网站文件不会主动清空它们。保持相同协议、域名、端口和浏览器
配置；迁移来源地址或设备时导出/导入 JSON。Docker 只托管网站文件，**不会备份个人航班
记录**。没有账号、云同步或可从服务器恢复的副本。

纪念身份独立保存在 localStorage，**不包含在 JSON 备份中**。开发期间旧版护照的完整
`KRF-…` 身份会确定性地迁移为九字符显示编号，保留原身份和昵称，不覆盖设置中的姓名。
清除存储或迁移来源地址可能产生新编号，该编号不保证全球唯一。PNG 包含姓名和编号，
分享前请自行检查。

Docker 用户下载并校验本版本安装器，指定
`--version v0.2.0 --dir /opt/keepraw-fly`，省略地址参数可保留现有域名与端口。
Fork Pages 用户在既有官方发行工作流中选择 v0.2.0；静态托管用户通过 HTTPS 部署已校验的
ZIP/tar.gz。完整前提和命令见[中文部署指南](../deployment.zh-CN.md)。

历史 Release、Tag 和镜像保持不变。v0.2.0 安装器可显式选择 v0.1.1 回滚，并校验文件和
镜像来源证明；v0.1.0 继续作为明确标识的 checksum-only 历史版本安装。先备份数据，
保留同一来源地址。通过部署历史恢复时需一起恢复 `compose.yaml`、`.env`、
`.keepraw-managed` 三个文件。

### 发行与已知限制

静态包及 linux/amd64、linux/arm64 Docker 镜像复用**完整 main Push CI 成功运行的原始
构建**。既有工作流要求 CI、Tag 和工作流源码提交一致，生成 SHA256SUMS、Provenance
以及分别用于附件和镜像的 Sigstore 证明。Owner-only 发布器验证来源和镜像匿名访问后，
由 **keepraw** 发布。安装器要求 GitHub CLI **2.102.0 或更新版本**，证明缺失或无效会
阻止安装，模拟测试不能替代真实验签。

- 不保证完整离线启动。CJK 护照字体可能从 jsDelivr 请求固定版本、经 SRI 校验的样式表；
  失败时使用系统字体，不同设备字形可能不同。该过程不上传航班记录。
- 距离或时间缺失时统计可能不完整，成品不会打印完整性提示。密集地图省略低频航线，
  无可用坐标的航线无法绘制。
- 姓名为空或文字无法编码时，MRZ 姓名字段可能未个性化。自动拼音不是经核实的护照
  拼写，必要时在设置中填写罗马字姓名。原生图片保存方式取决于浏览器。
- 浏览器清理或存储回收可能删除唯一的航班副本；持久存储授权不能代替下载 JSON 备份。

实现细节与合并记录见上文链接及[飞行护照规范](../flight-passport-journal.md)。
